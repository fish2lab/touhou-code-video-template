# 施工（模板）

## 工作包

| 包 | 只改这些文件 | 状态 |
|---|---|---|
| 骨架 | `src/core.js` `src/kit.js` `src/film.js` `index.html` `tools/` | 主会话 |
| 样板段 | `src/scenes/0-*.js`、`src/props.js` | 主会话 |
| 段 1 | `src/scenes/1-*.js` | 并行 |

## 接口

- 站位：`STD.pch` / `STD.cir`，脚底 y=880；帕秋莉站位区 x 205–455，琪露诺 x 1446–1754。
- 段首段末各 0.8 秒是标准画面：`spread` + 两人在 `STD` 站位 + 页眉。
- 字幕区 y≈930–1030；书脊 `CX` 两侧 ±20 不放字。
- 顶层名字带段前缀；只改自己的段文件；台词不改字；勤提交。

## 验收

每段：`node tools/overlap.mjs --scene 段名` → `node tools/frames.mjs --scene 段名 --grid 24` → 看图。
全片：`npm run voice && npm run render`。
