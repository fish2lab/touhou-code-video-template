# 人偶引擎 rig

`src/rig.js` 画所有角色，角色文件只放部件表，`drawXxx(c, o) = drawRig(c, 表, o)`。

## 统一比例（第三版，2026-10-08 起）

样板是帕秋莉（`src/character/patchouli.js`），照 Flash 短篇的 Q 版比例：不算帽子约 2.4 头身，脸宽约是肩宽的 2.3 倍。
**全员统一的是头和身子的大小，不再统一帽顶。** 部件表一律 `height: 520`，`h = 500` 对所有人是同一个缩放；帽子、耳朵、蝴蝶结这些头饰高出头顶多少，各人不同。
（旧规则是「帽顶到脚底 500」，Q 版以后会让没帽子的人脸更大，所以改了。）

设计坐标（`h = 520` 时，脚底 (0,0)，y 向下）：

| 部位 | 数值 |
|---|---|
| 脖子关节 | y = -248 |
| 下巴 / 头顶（头骨，不含头发蓬起和帽子） | y ≈ -253 / -428，脸高约 180 |
| 脸最宽处（颧骨、眼睛那一线） | ±77；圆脸，两颊鼓，下巴小 |
| 眼睛中心 | x = ±34，y = -313；睁开时 rx 15.6、ry 19.2（脸宽的 21%） |
| 刘海下缘 | 刚好压到眼睛上沿（约 -335 到 -360 一排尖） |
| 眉毛 / 嘴 / 腮红中心 | y -351 / -277 / (±50, -284) |
| 肩 | (±33, -234) |
| 上臂 / 前臂 | 各约 42 长，前臂末端是袖口，手指再出来约 14 |
| 裙摆下缘 | 约 y -54，钟形裙半宽约 82（各人裙形不同） |
| 鞋 | 中心 (±17, -10)，rx 17.5、ry 11 的圆鞋，鞋尖略朝前；裙摆和鞋之间露一截袜子 |

帕秋莉的做法：身子部件按脖子 -212 画、再乘 1.17，头部件在头坐标里画、再乘 1.2（`PCH_BODY`、`PCH_HEAD`）。rig 角色照样可以用 `XXX_HEAD` 缩放头骨头，只要最后落到上表的位置。

## 画法规则（第三版）

- **眼睛用 `face.style: 'layered'`**（rig.js）：眼白、虹膜、虹膜下半亮色、瞳孔、虹膜上沿阴影、两个高光、粗上眼线，八层，里面几层裁在眼白里。各人的眼神靠表情表里的 `lid`、`lidTilt`、`lower` 和颜色区分，不另写眼睛。
- **描边是深色细线**（rig.js 的 `rigEdge`，琪露诺和帕秋莉在各自文件里），纸纹和投影照旧。
- **腮红**：`face.blush.hatch = true` 加三道斜线。
- **帽子和头饰要包住头**（美术意见，2026-10-08）：不能是一块比头宽一大截、浮在头顶的扁片。帽子罩住整个头顶、盖住所有头发的顶部，两侧顺着头往下包；帽檐是绕头一圈的带子，正面看是一道弧（戴得往后仰时前沿高、两端低）；帽顶下沿贴着帽檐那道弧收进去；体积靠两层纸的明暗和从帽檐散开的褶子。不许有头发从帽子的两层之间露出来（穿模）。
- **拿东西的手**：袖子和袖口同一层，一起在被拿的东西后面；只有手指可以压到前面，而且要正好扣在东西的边上，不能浮在东西的面上。
- **发梢的蝴蝶结**系在胸口高度，下面再垂一截发尾，不要系到腰。
- 接口不变：姿势名、表情名、返回的锚点（head、hands、tip……）照旧，场景靠这些点摆道具。

## 部件表字段

- `K` 颜色，`G` 载入时剪好的部件（`rigCutter(种子偏移)`）
- `moods` 表情，`pose(姿势, g, tt)` 姿势，`mouth` 嘴型，`face` 五官尺寸（`lid` 或 `round` 两种眼睛）
- `arm` 肩位、臂长、手型
- `vars` 呼吸、晃动
- `bones` 骨头：`parent`、`at`、`rot`、`pivot`、`scale`、`sway`、`spring`、`sides`，字段可写成 `(k, sd) =>`
- `layers` 从后往前：`[部件, 骨头, 颜色键]`，`sh` 投影，`arms` 按手臂展开
- `anchors` 返回锚点

## 加一个角色

1. 复制 `remilia.js`，改前缀和种子偏移
2. 改颜色和部件轮廓，骨架尺寸先照抄
3. 从现有角色借嘴型、手型
4. `character.html` 的 `CH` 表加一项（fn、poses、moods），打开 `character.html?who=名字` 看样张

## 弹簧和光照

- 弹簧：`o.track = t => [x, y]` 给出锚点轨迹，挂件滞后 = 过去 0.5 秒加速度的阻尼加权和，纯函数。`spring = { len, dir, gain, f, zeta, max }`，不传 `track` 就没有弹簧。
- 光照：`o.light = { dir, warm, level }`。每片纸涂受光色，背光一侧剪一条背光带（短边 20%），投影落在光的对面，不传时和原来一样。

## 耗时

单个人偶约 5 ms/帧，开光照约 7 ms/帧（2026-09-30 实测）。
