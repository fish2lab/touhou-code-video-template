# 经验：什么让一集耐看

这是读完「帕秋莉讲座」第 1–3 集的代码和文档后的判断（不是观众数据）。第 1 集画面最丰富，第 2、3 集更「整齐」但显得单调。原因不在代码，在编排。

## 第 1 集为什么好看

- **每一页换一种编配**：剪纸灯箱、俯拍桌面定格、一根线的三维过山车、蓝晒星图、斜看的立体书。视觉语言每 1 分钟换一次，观众的眼睛始终有新东西。
- **每一页是一个「纸机关」**：转盘、立体书、拉条、图钉和线、硫酸纸——不只是「画个图」，是一个会动、能操作的小装置，有小动作和小笑点。
- **段与段之间形状接形状**：一个圆变成下一个东西，不是切镜头。
- **篇幅有余地**：多数段 450–600 行代码，全片近 7 分钟。

## 第 2、3 集为什么显得单调

1. **全片一个主物件**：第 2 集全片中段是同一张「冰的网络」，第 3 集是同一卷「打孔纸带」。逻辑上统一，视觉上从头到尾是同一幅画在变数值。
2. **只有两个角色、同一个站位**：为了「交接画面接得上」，两人全程钉在固定位置，不走动、不出画、不换景别。画面里能动的只剩中间那一块。
3. **克制过头**：为了让零基础观众跟得上，规则越加越多——新概念最多 3 个、每句只引入一个新元素、屏幕上只写正在念的关键词、关键句后停 1.2 秒。每条都对，叠在一起就是节奏很慢、信息很稀。
4. **每段更短、更薄**：第 3 集每段 100–430 行，有的只有 100 行，约 4.5 分钟。
5. **台词结构雷同**：「帕秋莉讲一句 → 琪露诺问一句 → 帕秋莉回答」的模式反复出现。
6. **复用带来的惯性**：第 2、3 集的引擎、画具、角色、舞台全是第 1 集的，只换了道具。观众看到的是同一个舞台。

## 下一集怎么避免

- **每 1 分钟换一次编配**，但保留两样不变的东西当「系列感」：魔导书舞台、两个角色。
- **一段一个主物件**，段与段之间换物件，用形状接形状。
- **让角色走动**：入画、出画、坐下、探头、把道具递给对方。标准站位只在段首段末，段中间可以动（`overlap.mjs` 照样检查）。
- **把「克制」放在颜色和字上，不要放在节奏上**：颜色少、字少没问题；但信息密度要有起伏，允许有一段「热闹」的，再回到安静。
- **台词里加一两个真正的转折或笑点**，别全是问答。
- **先做封面和前 15 秒**，再做其他。缩略图和开场决定有没有人看下去。

## 并行施工的做法

- 先由主会话做骨架和一个样板段，把画风钉死（颜色、线宽、字、节奏）。
- 再按文件拆包，每包一个 git worktree、一个 agent，只改自己的段文件。
- 段间交接画面（段首段末的标准画面）由主会话写进 `props.js`，各段只管自己的首尾。
- 合并后先抽联系表，再跑 `overlap.mjs`，最后逐段看整帧。agent 只按数值规格写时不要让它自己「看图改图」，容易越改越偏。
