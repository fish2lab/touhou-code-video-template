# 角色名单和挑选依据

模板里有十四个剪纸角色。前七位来自「帕秋莉讲座」前几集；后七位是按人气投票补的：取最近三届「東方Project人気投票」人妖部门（角色部门）前十名的并集，去掉已经有的人。
